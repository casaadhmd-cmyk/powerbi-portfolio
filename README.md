\##Power BI Portfolio

This repository contains Power BI dashboard projects created for data analysis and business insights using SQL and Power BI.

\##Projects

\#Customer Revenue Analysis Dashboard

This dashboard analyzes customer revenue, sales trends, and customer segmentation.It includes KPI cards for total sales, total orders, and total quantity.
Visualizations include sales trend over time, sales by customer segment, and sales by age group.Interactive slicers are used to filter data by date, customer segment, and age group.

\#Product Performance Dashboard
This dashboard analyzes product performance based on revenue, orders, and quantity sold.It includes KPI cards, sales trend analysis, category performance, and top-performing products.Interactive slicers allow users to filter by category, product, and date to analyze performance.
